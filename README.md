# Moloko Art Studios — бронирование и CRM

- `/` — виджет бронирования для клиентов (мобильный в первую очередь).
- `/studio` — CRM для администраторов и владельцев (iPad, ПК, телефон).

Стек: React 18, Vite, TypeScript, Tailwind 4, Supabase (Postgres, Auth, Realtime, Edge Functions), Vercel.

## Первый запуск
1. Откройте `/studio`: при первом входе создаётся аккаунт владельца.
2. В разделе «Команда» добавьте администраторов (логин и пароль).
3. Для проверки отчётов можно добавить демо-брони там же и потом удалить.

## Разработка
```bash
npm i
npm run dev
```
Переменные (необязательно, по умолчанию берётся проект Moloko Studio): `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`.

## База
Миграции лежат в `supabase/migrations`, функция для управления командой — `supabase/functions/moloko-staff`.
Пересечения броней запрещены на уровне базы, цены пересчитываются на сервере, бонусы начисляются по номеру телефона триггером после завершения съёмки.
